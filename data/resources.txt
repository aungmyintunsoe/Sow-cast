SOWCAST — DATA RESOURCES
========================
Updated 2026-11-14. "Provided" = named in the project README. "Added" = we wired it up. "Needed" = recommended next.

A. WHAT THE PIPELINE USES NOW (no keys, all working)
----------------------------------------------------
[provided] NASA POWER daily point API ........ heat, frost, rain, humidity, solar, soil wetness   https://power.larc.nasa.gov/
[provided] MODIS NDVI (MOD13Q1) via ORNL ...... green vs bare, 250 m, 16-day                       https://modis.ornl.gov/data/modis_webservice.html
[provided] NASA SRTM 30 m via OpenTopoData .... elevation, slope                                   https://www.opentopodata.org/
[added]    MODIS land cover (MCD12Q1) ......... checks sample points are on cropland
[added]    MODIS ET/PET (MOD16A2GF) ........... real evapotranspiration incl. irrigation
[added]    MODIS LST (MOD11A2) ................ 20-year land-surface heat (ECOSTRESS only starts 2018)
[added]    ISRIC SoilGrids 2.0 ................ global soil, replaces US-only SSURGO                 https://rest.isric.org/
[added]    NASA CMR search .................... inventory of login-only datasets                     https://cmr.earthdata.nasa.gov/

C. NEEDED — LOCAL GROUND TRUTH (to validate satellite numbers; all free)
-------------------------------------------------------------------------
Weather cross-checks (POWER is ~50 km grid; these are finer / station-based):
  - CHIRPS rainfall, 5 km, global tropics — best for Nakuru          https://www.chc.ucsb.edu/data/chirps
  - SILO (Queensland Gov) station-based grids — Darling Downs frost   https://www.longpaddock.qld.gov.au/silo/
  - IMD gridded rainfall/temperature — Punjab                         https://www.imdpune.gov.in/
  - PRISM 4 km / Iowa Environmental Mesonet — Iowa                    https://prism.oregonstate.edu/  https://mesonet.agron.iastate.edu/
Crop calendars & what is actually grown (for rotations + backtesting crop_fit):
  - USDA NASS Cropland Data Layer + QuickStats (free API key) — Iowa  https://nassgeodata.gmu.edu/CropScape/  https://quickstats.nass.usda.gov/api
  - GEOGLAM / FAO crop calendars — all sites                          https://cropmonitor.org/  https://www.fao.org/agriculture/seed/cropcalendar
  - FAOSTAT country crop yields                                       https://www.fao.org/faostat/
  - ABARES (Australia), India DES district yields, Kenya KNBS / MoA county data
Soil validation:
  - USDA SSURGO / Web Soil Survey — Iowa                              https://websoilsurvey.nrcs.usda.gov/
  - APSoil characterised profiles — Darling Downs (SoilGrids under-estimates its clay water capacity)
Groundwater validation:
  - CGWB well levels — Punjab                                         https://cgwb.gov.in/
  - USGS NWIS wells — Iowa                                            https://waterdata.usgs.gov/

D. NEEDED — PEOPLE / DOMAIN INPUT
---------------------------------
  - An agronomist (or extension service doc) per region to sanity-check the thresholds: heat 35 °C, heavy rain 20 mm, bare NDVI 0.3.
  - Real crop-season months for each crop in each region (the app's crops.json has temperatures but not regional sowing dates).
  - Farmer feedback on the insight-card wording.

E. NICE TO HAVE
---------------
  - Google Earth Engine account — field-polygon NDVI instead of single pixels, any region in minutes.
  - Sentinel-1 radar (Copernicus) — sees crops through monsoon/rainy-season clouds (Punjab Jul–Sep, Nakuru).
  - NASA FIRMS active fire — stubble burning after rice harvest in Punjab (Oct–Nov) affects bare-soil signal.
