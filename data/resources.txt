SOWCAST — DATA RESOURCES
========================
Updated 2026-11-14. Scope: 23 regions in Myanmar, Thailand, Vietnam, Cambodia. Open data only (no logins).

A. IN USE (no keys, all wired into data/scripts)
------------------------------------------------
NASA POWER daily point API ........ heat, frost, rain, humidity, solar, soil wetness   https://power.larc.nasa.gov/
MODIS via ORNL DAAC web service ... NDVI (MOD13Q1), land cover (MCD12Q1),              https://modis.ornl.gov/data/modis_webservice.html
                                    ET/PET (MOD16A2GF), land-surface temp (MOD11A2)
ISRIC SoilGrids 2.0 ............... soil texture, carbon, pH, water retention           https://rest.isric.org/
NASA SRTM 30 m via OpenTopoData ... elevation -> slope for erosion risk                 https://www.opentopodata.org/
CHIRPS via SERVIR ClimateSERV ..... daily rain, ~5 km (rain source for all regions)     https://climateserv.servirglobal.net/
ERA5 via Open-Meteo archive ....... daily temperature where POWER is broken             https://open-meteo.com/en/docs/historical-weather-api
NASA GIBS (decoded tiles) ......... monthly VIIRS NDVI on cropland 2012-2024            https://gibs.earthdata.nasa.gov/
NASA GIBS (app map) ............... greenness, satellite photo, IMERG rain, SMAP soil moisture,
                                    surface heat, land cover, floods, elevation, place names

B. ON THIS MACHINE
------------------
Node 24 ........ runs the fetch scripts (no npm install needed)
Python 3.15.2 .. installed; analysis venv at data/.venv with pandas, numpy, scipy, matplotlib,
                 plotly, jupyterlab, pymannkendall (see requirements.txt).
                 Restart terminals / VS Code so `python` is on PATH.

C. WORTH GETTING — FREE, NO LOGIN (details and priority: NEXT_STEPS.md Part B)
-------------------------------------------------------------------------------------
Crop calendars (needed for ground cover by month and season windows):
  - FAO GIEWS country briefs (Myanmar, Thailand, Viet Nam, Cambodia)   https://www.fao.org/giews/
  - USDA FAS IPAD crop calendars, Southeast Asia                     https://ipad.fas.usda.gov/
  - GEOGLAM Crop Monitor                                             https://cropmonitor.org/
Land, water and risk:
  - JRC Global Surface Water — flood frequency                       https://global-surface-water.appspot.com/
  - Mekong River Commission — salinity / flood reports               https://www.mrcmekong.org/
  - FAO GMIA / AQUASTAT — irrigated area                             https://www.fao.org/aquastat/
Yields, area, prices (market score + backtesting crop fit):
  - FAOSTAT (bulk CSV)                                               https://www.fao.org/faostat/
  - National statistics: Thailand OAE, Vietnam GSO, Myanmar MOALI, Cambodia MAFF

D. PEOPLE / DOMAIN INPUT
------------------------
  - An agronomist or extension-service document per region to sanity-check thresholds:
    heat 35 °C, heavy rain 20 mm, bare NDVI 0.3.
  - Regional sowing/harvest months for each crop (crops.json has temperature limits but no calendars).
  - Farmer feedback on insight-card wording.

E. DELIBERATELY OUT OF SCOPE FOR THE DEMO
-----------------------------------------
  Login-only NASA data: SMAP, GPM IMERG, ECOSTRESS, GRACE-FO, Landsat/HLS (need an Earthdata account).
  True-colour imagery and label layers on the map (the map shows NASA plant greenness only).
  -> Consequence: no groundwater data. The groundwater card becomes a "water budget" card (NEXT_STEPS.md §2).
